# 古錢推幣機朋友2（Android・iOS 版）隱私權政策

**【譯本說明】本中文版為參考譯本，以日文版為正本；如有不一致，以日文版為準，但您所在國家或地區之法律另有規定者，從其規定。**

株式會社STP WORKS（以下稱「本公司」）就智慧型手機及平板電腦用遊戲應用程式「古錢推幣機朋友2」（Android 版及 iOS 版，以下稱「本應用程式」），以及透過本應用程式提供之線上功能（以下與本應用程式合稱「本服務」）中使用者資訊之處理，訂定如下。
本公司網站中資訊之處理，依本公司網站之隱私權政策辦理。

## 1. 本公司取得之資訊

本應用程式取得下列資訊。

| 種類 | 內容 | 取得方式 |
|---|---|---|
| 玩家名稱 | 使用者於本應用程式中設定之名稱（未設定時為「Player」加上4位數字） | 使用者輸入 |
| 識別用資訊 | 本應用程式於裝置上產生之隨機 ID、本公司使用之伺服器所核發之玩家 ID、每次啟動時產生之暫時性數值 | 由本應用程式自動產生及傳送 |
| 遊戲紀錄 | 評價、累計遊玩時間、遊玩之裝置種類（Android／iOS）、線上遊玩期間之遊戲狀況（房間、暗號、傳送之貼圖、發射硬幣等操作） | 由本應用程式自動傳送 |
| 疑似作弊紀錄 | 本應用程式偵測到變更遊戲速度或竄改記憶體時之偵測種類、日期時間及本應用程式之版本 | 由本應用程式自動傳送 |
| 通訊相關資訊 | IP 位址、通訊日期時間、依登入時之 IP 位址推估之國家、城市等大略位置 | 隨通訊自動取得 |
| 資料移轉用資訊 | 使用者於本應用程式中選擇「產生轉移碼」時之遊戲紀錄副本（於裝置上加密者），以及由轉移碼產生之數值（不傳送轉移碼本身） | 使用者之操作 |
| 營運處置紀錄 | 本公司依使用條款變更玩家名稱或修正評價之指示，以及本應用程式套用該指示之日期時間 | 由本公司設定，並由本應用程式自動傳送 |
| 檢舉資訊 | 使用者檢舉其他玩家時之對方玩家名稱、對方玩家 ID（自排行榜檢舉時）、檢舉理由、檢舉之位置（排行榜・房間）及房間名稱、日期時間、使用者之玩家名稱 | 使用者之操作 |
| 刪除申請紀錄 | 自本應用程式申請刪除帳號時之日期時間、玩家名稱、裝置種類、本應用程式之版本 | 使用者之操作 |
| 詢問資訊 | 電子郵件地址、詢問內容、遊戲內 ID・驗證碼 | 使用者寄送之電子郵件 |

本應用程式於使用者初次啟動並同意使用條款及本政策之前，不會向本公司或第4節之事業者傳送任何資訊。
本應用程式不取得姓名、地址、電話號碼、出生年月日、裝置之位置資訊（GPS）、通訊錄、照片、麥克風・相機、廣告 ID、各裝置之識別碼。本應用程式價款之支付由商店（Google Play・App Store）處理，本公司不會收到支付資訊。

## 2. 利用目的

本公司為下列目的利用所取得之資訊：

1. 提供本服務（建立及識別帳號、保存遊戲紀錄、更換裝置時之資料移轉、同一帳號於多台裝置使用時之判定）
2. 提供與其他使用者線上一起遊玩之功能
3. 統計並顯示本應用程式與其他平台版本（Steam 版・Nintendo Switch 版）共通之排行榜
4. 防止、調查及處理不正行為或違反使用條款之行為（包含修正評價、停止使用等處置）
5. 調查並修正程式錯誤，改善本服務
6. 回覆詢問，並確認是否為本人
7. 通知本服務之變更、中斷、終止等重要事項
8. 依法令辦理

本公司不將所取得之資訊用於投放廣告或行銷。此外，本公司不販售使用者之資訊。

## 8. 帳號及資料之刪除 {#delete}

使用者得以下列任一方式，請求刪除帳號及本公司所保存之使用者資訊。

1. **透過本應用程式**：可自【設定】之【刪除帳號和資料】辦理。
   本裝置之遊戲紀錄將立即刪除，下次啟動時將以新帳號開始。本公司伺服器上之紀錄，將依下一段所述刪除。
2. **不透過本應用程式**（刪除本應用程式後等情形）：請自【刪除申請頁面之 URL】，或寄送電子郵件至 support@stp.works，並附上本應用程式【設定】中顯示之【遊戲內 ID】及【驗證碼】、玩家名稱提出申請。不清楚遊戲內 ID 時，請告知玩家名稱及最後遊玩之大約日期時間。本公司將比對您提供之資訊與本公司之紀錄，確認申請係由本人提出。

本公司將於收到申請後【30日】內，刪除帳號及與其連結之玩家名稱・遊戲紀錄・疑似作弊紀錄・登入紀錄・資料移轉用資訊，並自排行榜中刪除（第7節所定刪除後仍保存之紀錄除外）。本公司委託處理資訊之事業者（第4節）處之紀錄，亦將一併刪除。已刪除之帳號及遊戲紀錄無法復原。

如欲停止向本服務傳送資訊，亦請以此方式刪除帳號，並自裝置刪除本應用程式。

## 9. 安全管理措施

本公司為防止所取得之資訊洩漏、滅失或毀損，採取下列措施。

1. 制定基本方針：為適當處理資訊，訂定本政策。
2. 處理之規範：訂定取得、利用、保存、刪除之方法及負責人。
3. 組織上之措施：設置處理之負責人，並建立於掌握違反法令或本政策之事實或徵兆時之通報體制。
4. 人員上之措施：向處理資訊之從業人員宣導處理時之注意事項。
5. 物理上之措施：防止處理資訊之機器遭竊或遺失，並管理處理資訊之區域。
6. 技術上之措施：限制可進入管理畫面之人員，並採取防止外部非法存取之措施。本應用程式之遊戲紀錄，係於裝置內加密保存。

| 當事人得行使之權利及方式 | 得查詢或請求閱覽、請求製給複製本、請求補充或更正、請求停止蒐集、處理或利用，以及請求刪除。方式如第8節及第12節所述 |
| 不提供個人資料對權益之影響 | 未設定玩家名稱時，將使用「Player」加上4位數字之名稱。識別用資訊及遊戲紀錄之傳送為線上功能（與其他使用者一起遊玩之功能・排行榜）所不可或缺，如不願提供，將無法使用線上功能 |

### 15-3. 致居住於香港・澳門之使用者

1. **蒐集之目的**：如第2節所述。
2. **資訊提供對象之類別**：第4節之事業者（受託處理資訊之事業者），以及於排行榜及同一房間中顯示之其他使用者。本公司將管理受託之事業者，使其依契約僅於本公司指示之範圍內處理資訊。
3. **是否必須提供**：玩家名稱之設定為任意。識別用資訊及遊戲紀錄為線上功能所不可或缺（與15-2之「不提供個人資料對權益之影響」相同）。
4. **閱覽及更正之請求**：使用者得請求閱覽及更正其資訊。請求請寄至第13節之窗口（株式會社STP WORKS，support@stp.works）。
5. **向澳門境外之移轉**：使用者之資訊，將移轉至15-1第1項之國家處理。【澳門法律所要求之程序（同意・向主管機關通知），將經律師確認後訂定】

### 15-4. 致居住於美國・澳洲・紐西蘭等地之使用者

1. 使用者之資訊，僅為委託第4節之事業者進行提供本服務所需之處理之目的，提供予該等事業者。
2. 加州居民得以第8節及第12節之方式，請求知悉、訂正及刪除本公司所持有之其本人資訊。變更本政策時，將以第14節之方式通知，並於本政策中載明生效日。
3. 澳洲居民得向 Office of the Australian Information Commissioner（OAIC），紐西蘭居民得向 Office of the Privacy Commissioner，提出申訴。
