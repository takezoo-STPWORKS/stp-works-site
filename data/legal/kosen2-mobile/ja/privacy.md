# 古銭プッシャーフレンズ2（Android・iOS 版）プライバシーポリシー

株式会社STP WORKS（以下「当社」）は、スマートフォン・タブレット向けのゲームアプリ「古銭プッシャーフレンズ2」（Android 版および iOS 版。以下「本アプリ」）と、本アプリを通じて提供するオンラインの機能（以下、本アプリとあわせて「本サービス」）における、利用者の情報の取扱いを次のとおり定めます。
当社のウェブサイトにおける情報の取扱いは、当社のウェブサイトのプライバシーポリシーによります。

## 1. 当社が取得する情報

本アプリでは、次の情報を取得します。

| 種類 | 内容 | 取得の方法 |
|---|---|---|
| プレイヤー名 | 利用者が本アプリで設定する名前（設定しない場合は「Player」と4桁の数字） | 利用者の入力 |
| 識別のための情報 | 本アプリが端末で作るランダムな ID、当社が利用するサーバーが発行するプレイヤー ID、起動のたびに作る一時的な値 | 本アプリが自動で作成・送信 |
| ゲームの記録 | 評価値、累計のプレイ時間、遊んでいる端末の種類（Android／iOS）、オンラインで遊んでいる間のゲームの状況（部屋、合言葉、送ったスタンプ、コインの発射などの操作） | 本アプリが自動で送信 |
| 不正の疑いの記録 | 本アプリが、ゲームの速度の変更やメモリの書き換えを検出したときの、検出の種類・日時・本アプリの版 | 本アプリが自動で送信 |
| 通信に関する情報 | IP アドレス、通信の日時、ログインしたときの IP アドレスから推定される国・都市などのおおよその場所 | 通信に伴い自動で取得 |
| 引き継ぎのための情報 | 利用者が本アプリで「引き継ぎコードを出す」を選んだときの、ゲームの記録の写し（端末で暗号化したもの）と、引き継ぎコードから作った値（引き継ぎコードそのものは送りません） | 利用者の操作 |
| 運営の措置の記録 | 当社が利用規約に基づいて変更したプレイヤー名や評価値の修正の指示と、本アプリがそれを反映した日時 | 当社が設定し、本アプリが自動で送信 |
| 通報の情報 | 利用者が他のプレイヤーを通報したときの、相手のプレイヤー名、相手のプレイヤー ID（ランキングから通報した場合）、通報の理由、通報した場所（ランキング・部屋）と部屋の名前、日時、利用者のプレイヤー名 | 利用者の操作 |
| 削除の依頼の記録 | 本アプリからアカウントの削除を依頼したときの日時、プレイヤー名、端末の種類、本アプリの版 | 利用者の操作 |
| お問い合わせの情報 | メールアドレス、お問い合わせの内容、ゲーム内の ID・確認コード | 利用者からのメール |

本アプリは、初めて起動したときに利用規約と本ポリシーへの同意をいただくまで、当社や第4項の事業者に情報を送信しません。
本アプリは、氏名、住所、電話番号、生年月日、端末の位置情報（GPS）、連絡先、写真、マイク・カメラ、広告 ID、端末ごとの識別子を取得しません。本アプリの代金の支払いはストア（Google Play・App Store）が取り扱い、当社は支払いの情報を受け取りません。

## 2. 利用の目的

当社は、取得した情報を次の目的で利用します。

1. 本サービスを提供するため（アカウントの作成と識別、ゲームの記録の保存、機種変更の際の引き継ぎ、同じアカウントを複数の端末で使ったときの判定）
2. 他の利用者とオンラインで一緒に遊ぶ機能を提供するため
3. 本アプリと他機種版（Steam 版・Nintendo Switch 版）で共通のランキングを集計し、表示するため
4. 不正行為や利用規約に違反する行為を防ぎ、調査し、対応するため（評価値の修正、利用の停止などの措置を含みます）
5. 不具合を調べて直し、本サービスを改善するため
6. お問い合わせに対応し、ご本人であることを確認するため
7. 本サービスの変更、中断、終了など、重要なお知らせをするため
8. 法令に基づく対応のため

当社は、取得した情報を広告の配信やマーケティングに利用しません。また、利用者の情報を販売しません。

## 3. 他の利用者に表示される情報

1. プレイヤー名、評価値、累計のプレイ時間は、**ランキングで、本アプリと他機種版（Steam 版・Nintendo Switch 版）のすべての利用者に表示されます。**
2. オンラインで一緒に遊んでいる他の利用者（他機種版の利用者を含みます）には、プレイヤー名、送ったスタンプ、ゲームの状況が表示されます。
3. 合言葉で遊ぶ部屋の名前には合言葉が含まれます。本アプリで作った合言葉の部屋は部屋の一覧に表示しませんが、同じ部屋に入った人や、他機種版で作られた部屋を通じて、合言葉が他の利用者に知られることがあります。プレイヤー名や合言葉に、ご自身や他人の個人情報を使わないでください。

## 8. アカウントとデータの削除 {#delete}

利用者は、次のいずれかの方法で、アカウントと、当社が保存している利用者の情報の削除を求めることができます。

1. **本アプリから**：「設定」の「アカウントとデータの削除」から手続きできます。
   この端末のゲームの記録はその場で消え、次に起動すると新しいアカウントで始まります。当社のサーバーの記録は、次の段落のとおり削除します。
2. **本アプリを使わずに**（本アプリを削除した後など）：support@stp.works あてのメールで、本アプリの「設定」に表示される「ゲーム内の ID」と「確認コード」、プレイヤー名を添えて依頼してください。ゲーム内の ID が分からない場合は、プレイヤー名と、最後に遊んだおおよその日時をお知らせください。当社は、いただいた情報と当社の記録を照らし合わせて、ご本人からの依頼であることを確認します。

当社は、依頼を受けてから30日以内に、アカウントと、それに結び付くプレイヤー名・ゲームの記録・不正の疑いの記録・ログインの記録・引き継ぎのための情報を削除し、ランキングからも削除します（第7項で削除後も保存すると定めた記録を除きます）。当社が情報の取扱いを任せている事業者（第4項）の側の記録も削除します。削除したアカウントとゲームの記録は元に戻せません。

本サービスへの情報の送信をやめたい場合も、この方法でアカウントを削除し、本アプリを端末から削除してください。

## 9. 安全管理のための措置

当社は、取得した情報の漏えい、滅失、き損を防ぐため、次の措置を講じています。

1. 基本方針の策定：情報の適正な取扱いのため、本ポリシーを定めています。
2. 取扱いの規律：取得、利用、保存、削除の方法と責任者を定めています。
3. 組織的な措置：取扱いの責任者を置き、法令や本ポリシーに反する事実やその兆しを把握したときの報告の体制を整えています。
4. 人的な措置：情報を扱う従業者に、取扱いの注意を周知しています。
5. 物理的な措置：情報を扱う機器の盗難・紛失を防ぎ、情報を取り扱う区域を管理しています。
6. 技術的な措置：管理の画面に入れる人を限り、外部からの不正なアクセスを防ぐ措置を講じています。本アプリのゲームの記録は、端末の中で暗号化して保存しています。
7. 外的環境の把握：外国にある事業者に情報の取扱いを任せるにあたり、その国（アメリカ合衆国）の個人情報の保護の制度を把握したうえで、安全管理のための措置を講じています（第5項）。

| 提供しない場合の影響 | プレイヤー名を設定しない場合は「Player」と4桁の数字の名前になります。識別のための情報やゲームの記録の送信は、オンラインの機能（他の利用者と一緒に遊ぶ機能・ランキング）に欠かせないため、これを望まない場合はオンラインの機能を使えません |
| 本人以外から得る情報 | ログインしたときの IP アドレスから推定されるおおよその場所は、Microsoft（Azure PlayFab）が作るものです |

### 15-3. 香港・マカオに住む利用者の方へ

1. **集める目的**：第2項のとおりです。
2. **情報を渡す相手の種類**：第4項の事業者（情報の取扱いを任せる事業者）と、ランキングと同じ部屋で表示される他の利用者です。当社は、任せた事業者が、契約に基づき、当社の指示の範囲でだけ情報を扱うよう管理します。
3. **提供が必要かどうか**：プレイヤー名の設定は任意です。識別のための情報とゲームの記録は、オンラインの機能に欠かせません（15-2 の「提供しない場合の影響」と同じです）。
4. **開示と訂正の求め**：利用者は、自分の情報の開示と訂正を求めることができます。求めは第13項の窓口（株式会社STP WORKS、support@stp.works）にお送りください。
5. **マカオの外への移転**：利用者の情報は、15-1 第1項の国へ移して扱います。

### 15-4. アメリカ合衆国・オーストラリア・ニュージーランドなどに住む利用者の方へ

1. 利用者の情報は、第4項の事業者に、本サービスを提供するための処理を任せる目的でだけ渡します。
2. カリフォルニア州の住民の方は、第8項と第12項の方法で、当社が持つ自分の情報の内容を知り、訂正し、削除することを求めることができます。本ポリシーを変えるときは、第14項の方法で知らせ、効力が生じる日を本ポリシーに示します。
3. オーストラリアの住民の方は Office of the Australian Information Commissioner（OAIC）に、ニュージーランドの住民の方は Office of the Privacy Commissioner に、苦情を申し立てることができます。
